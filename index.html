Brand Platform Format 🏷️ ประเภท Topic Caption Date Shares Saves Comments Likes Views ER % Quality % Like Rate % Total Eng #Tags Link
📐 สูตรคำนวณ Metric:
• ER % (Engagement Rate per-platform) — คิดเฉพาะ field ที่ platform เปิด public:
   ◦ TikTok / Facebook: (Like + Comment + Share) ÷ View × 100
   ◦ YouTube / Instagram: (Like + Comment) ÷ View × 100 (IG/YT ไม่เปิด share, save public)
   ◦ ถ้า View = 0 หรือ Platform ไม่มี view → แสดง — (เพราะ benchmark ข้าม platform ไม่ fair)
• Quality % (CLR) = Comment ÷ Like × 100
   = วัด คุณภาพ engagement — Comment ใช้ effort สูงกว่า Like มาก. ตัวเลขสูง = content กระตุ้นบทสนทนา
• Like Rate % (LVR) = Like ÷ View × 100
   = วัด stopping power — คนเลื่อนผ่านแล้วหยุดดู+กด like มากแค่ไหน. ตัวเลขสูง = content ปังจริง
Avg ใน KPI card = เฉลี่ยเฉพาะ posts ที่คำนวณได้ (กัน N/A ฉุดค่า)

ℹ️ ข้อจำกัด data: Save/Share บน Instagram และ YouTube = Meta/Google ไม่เปิด public — ดูได้แค่ของ account ตัวเองผ่าน Insights/Studio
